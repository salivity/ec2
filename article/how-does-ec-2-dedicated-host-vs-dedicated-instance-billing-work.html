How Does EC2 Dedicated Host vs Dedicated Instance Billing Work?

The primary billing difference between Amazon EC2 Dedicated Hosts and Dedicated Instances lies in the unit of charge and the presence of a regional fee. With Dedicated Hosts, you pay a fixed hourly rate for an entire physical server regardless of how many virtual instances you launch on it. With Dedicated Instances, you pay an hourly fee for each individual instance you run, plus a flat two-dollar per hour regional fee as long as at least one Dedicated Instance of any family is active in that AWS Region. Understanding these billing mechanics helps organizations optimize cloud infrastructure expenses when physical hardware isolation is required.

Amazon EC2 Dedicated Hosts Billing Model

When you allocate an Amazon EC2 Dedicated Host, AWS dedicates an entire physical server to your account. You are billed strictly per physical host on an hourly or per-second basis, depending on the instance family configuration and operating system.

Fixed Hardware Capacity Pricing

Once a Dedicated Host is allocated in your account, billing begins immediately, even if zero instances are currently running on it. However, launching instances onto an allocated Dedicated Host incurs no additional compute charges for the instances themselves. If a physical host has the capacity to run sixteen small instances or four large instances, the hourly compute cost remains identical whether the host is empty, partially utilized, or completely full.

Let \(C_{\text{host}}\) represent the hourly rate of a single Dedicated Host and \(H\) represent the total number of allocated hosts. The total hourly compute cost \(T_{\text{host}}\) is expressed as:

\[T_{\text{host}} = H \times C_{\text{host}}\]

Notice that the number of running instances \(N\) does not appear in this equation, provided the instances fit within the physical capacity of the \(H\) hosts.

Software Licensing Impact on Billing

A major financial advantage of the per-host billing model is its compatibility with Bring Your Own License (BYOL) software agreements. Because Dedicated Hosts provide visibility into the exact number of physical sockets and physical cores on the server, you can bind existing per-socket or per-core enterprise licenses—such as Windows Server, SQL Server, or Oracle—directly to the hardware. This avoids paying AWS for license-included instance rates.

Amazon EC2 Dedicated Instances Billing Model

Dedicated Instances also run on hardware dedicated to a single customer, but the management of the underlying physical servers is abstracted away by AWS. Consequently, the billing structure mirrors standard EC2 instance pricing with an additional surcharge for hardware isolation.

Per-Instance Usage Plus Regional Fee

With Dedicated Instances, there are two distinct cost components:

  1. Per-Instance Hourly Rate: You pay for each running Dedicated Instance based on its instance type and size. This rate is typically slightly higher than standard shared-tenancy On-Demand instances.
  2. Per-Region Hourly Fee: AWS charges a flat fee of \(\$2.00\) per hour for each Region in which you have at least one running Dedicated Instance. Whether you run one Dedicated Instance or one hundred Dedicated Instances across multiple instance families within the same Region, this regional fee remains a flat \(\$2.00\) per hour.

Let \(N\) be the number of active Dedicated Instances in a single Region, and \(C_i\) be the hourly rate for the \(i\)-th instance. For \(N \ge 1\), the total hourly compute cost \(T_{\text{instance}}\) is:

\[T_{\text{instance}} = 2.00 + \sum_{i=1}^{N} C_i\]

If all Dedicated Instances in that Region are stopped or terminated (\(N = 0\)), both the per-instance charges and the \(\$2.00\) regional fee stop accruing.

Cost Comparison and Break-Even Analysis

Choosing the most cost-effective option depends heavily on your hardware utilization rate and workload scale.

Low Volume or Variable Workloads

If you only need to run a few isolated instances or if your workload scales up and down frequently, Dedicated Instances are usually less expensive. Paying for one or two instances plus the \(\$2.00\) regional fee costs significantly less than paying for an entire physical Dedicated Host that sits mostly idle. Furthermore, when traffic drops, terminating Dedicated Instances immediately scales your compute bill down, whereas a Dedicated Host continues to bill at 100% capacity until you terminate all instances on it and explicitly release the host.

High Volume and Predictable Workloads

As you scale up the number of instances of the same family, Dedicated Hosts become much more economical. When you pack a Dedicated Host to near 100% capacity, the effective cost per instance drops below the per-instance rate of Dedicated Instances, and you avoid the \(\$2.00\) regional fee entirely.

To find the break-even point for a homogeneous fleet of instances of size \(s\), let \(K\) be the maximum number of instances of size \(s\) that can fit on a single Dedicated Host, and let \(C_s\) be the hourly rate of a single Dedicated Instance of that same size. A single Dedicated Host becomes cheaper than running \(N\) Dedicated Instances (where \(1 \le N \le K\)) when:

\[C_{\text{host}} < 2.00 + (N \times C_s)\]

Solving for \(N\) gives the minimum number of instances required on a single host to justify per-host billing:

\[N > \frac{C_{\text{host}} - 2.00}{C_s}\]

Purchasing Options and Discounts

Both billing models support AWS commitment discounts, though they apply at different levels:

  • On-Demand: Pay by the hour or second with no long-term commitments. Dedicated Hosts charge while allocated; Dedicated Instances charge while running.
  • Savings Plans: Compute Savings Plans and EC2 Instance Savings Plans apply to both Dedicated Hosts and Dedicated Instances, automatically reducing the hourly host rate or the per-instance rate in exchange for a 1-year or 3-year hourly spend commitment. Note that Savings Plans do not cover the \(\$2.00\) per hour regional fee for Dedicated Instances unless there is sufficient commitment to cover usage, and typically the regional fee is billed separately from standard instance compute rates.
  • Reservations: You can purchase Dedicated Host Reservations to receive a substantial discount on the hourly host fee, or purchase Reserved Instances with Dedicated tenancy to discount the per-instance charges of Dedicated Instances.
  • Spot Instances: Dedicated Instances can be launched as Spot Instances to take advantage of spare AWS capacity at steep discounts, whereas Dedicated Hosts do not support a Spot purchasing model for the physical host itself.

Summary of Key Billing Differences

Billing Feature EC2 Dedicated Hosts EC2 Dedicated Instances
Primary Unit of Charge Per allocated physical server Per running virtual instance
Regional Surcharge None \(\$2.00\) per hour per active Region
Cost When Instances Are Stopped Full host rate continues until host is released Compute and regional fees drop to \(\$0.00\) (if all instances are stopped)
Cost of Adding Instances \(\$0.00\) for additional instances that fit on an existing host Linearly increases with each new instance launched
BYOL License Cost Impact Supports per-core and per-socket BYOL to eliminate license fees Limited BYOL support; usually requires license-included rates
Best Financial Fit High-density, steady-state workloads or strict BYOL requirements Small instance counts, mixed instance families, or elastic workloads
