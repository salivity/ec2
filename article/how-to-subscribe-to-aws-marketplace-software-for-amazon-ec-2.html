How to Subscribe to AWS Marketplace Software for Amazon EC2?

Subscribing to and deploying third-party software appliances through AWS Marketplace for Amazon EC2 streamlines the procurement and provisioning process within cloud environments. This guide covers the essential steps required to browse the catalog, evaluate pricing and licensing terms, subscribe to an Amazon Machine Image product, and launch the configured software directly onto an Amazon EC2 instance. It also explains how to manage ongoing subscriptions, configure IAM permissions, and monitor associated software and infrastructure costs through AWS Billing.

Prerequisites and IAM Permissions

Before subscribing to third-party software on AWS Marketplace, ensure that your AWS account is active, has a valid payment method on file, and has the appropriate Identity and Access Management (IAM) permissions configured. By default, root account users have full access to AWS Marketplace, but IAM users and roles require explicit policies to subscribe to and launch products.

To allow an IAM user to subscribe to and manage AWS Marketplace products, attach the AWSMarketplaceFullAccess or AWSMarketplaceManageSubscriptions managed policy. Additionally, the user will need standard Amazon EC2 permissions (such as AmazonEC2FullAccess or a custom policy allowing ec2:RunInstances, ec2:DescribeImages, and ec2:CreateSecurityGroup) to deploy the software appliance as an EC2 instance.

Step 1: Discover and Evaluate Software Appliances

There are two primary entry points for finding third-party Amazon Machine Image (AMI) appliances: the standalone AWS Marketplace website (or AWS Management Console service page) and the Amazon EC2 Launch Instance wizard.

  1. Open the AWS Management Console and navigate to AWS Marketplace Subscriptions, or go directly to the EC2 Console and select Launch instance.
  2. In the AWS Marketplace console, select Discover products from the left navigation pane.
  3. Use the search bar and filters to narrow down your selection:
    • Delivery method: Select Amazon Machine Image (AMI) to filter specifically for EC2-compatible virtual appliances.
    • Pricing Plan: Filter by Free Trial, Bring Your Own License (BYOL), Hourly, Monthly, or Annual pricing.
    • Categories: Filter by Networking, Security, Databases, Operating Systems, or Business Applications.
  4. Click on a product listing to review its Product Overview, including supported EC2 instance types, operating system details, architecture (x86_64 or arm64), and vendor support terms.

Step 2: Understand Pricing Models and Total Cost

Third-party software appliances on AWS Marketplace typically involve two distinct cost components: the software license fee (set by the independent software vendor) and the AWS infrastructure fee (for the underlying EC2 compute, EBS storage, and data transfer).

Common licensing models include:

  • Hourly or Usage-Based (Pay-As-You-Go): Billed per hour or per second that the EC2 instance is running, scaled by the size of the instance.
  • Annual or Multi-Year Contract: Upfront or scheduled payments for long-term usage at a discounted rate compared to hourly billing ( underlying EC2 infrastructure is still billed separately).
  • Bring Your Own License (BYOL): No software charges are incurred through AWS Billing; instead, you apply an existing license key obtained directly from the vendor after launching the instance.
  • Seller Private Offers: Custom-negotiated pricing and End User License Agreement (EULA) terms tailored specifically for your AWS account or AWS Organization.

For usage-based AMI products, the total hourly cost \(C_{\text{total}}\) can be expressed as:

\[C_{\text{total}} = C_{\text{software}}(t) + C_{\text{EC2}}(t) + C_{\text{storage}}\]

where \(C_{\text{software}}(t)\) is the vendor's hourly software rate for instance type \(t\), \(C_{\text{EC2}}(t)\) is the Amazon EC2 compute rate for instance type \(t\), and \(C_{\text{storage}}\) represents the prorated cost of attached Amazon EBS volumes.

Step 3: Subscribe to the Software Product

Once you have verified the pricing and technical requirements, you must accept the vendor's terms to activate the subscription for your AWS account.

  1. On the product detail page, click Continue to Subscribe in the upper-right corner.
  2. Review the End User License Agreement (EULA) and the refund policy.
  3. If the product offers an Annual or Hourly option, select your preferred contract terms and configure auto-renewal settings if applicable.
  4. Click Accept Terms (or Subscribe).
  5. Wait for the subscription request to process. The status will transition from Pending to Subscribed, and the Continue to Configuration button will become active.

Step 4: Configure the Software and Launch on Amazon EC2

After your subscription is active, configure the deployment parameters and launch the virtual appliance onto an EC2 instance.

  1. Click Continue to Configuration on the subscription page.
  2. Specify the following configuration options:
    • Fulfillment option: Select Amazon Machine Image (AMI) (or a vendor-provided AWS CloudFormation template if offered for multi-instance architectures).
    • Software version: Select the desired release version of the appliance.
    • Region: Choose the AWS Region where you want to deploy the EC2 instance. Note that AMI IDs are region-specific.
  3. Click Continue to Launch.
  4. Under Choose Action, select one of the following methods:
    • Launch from Website: Allows you to deploy the instance directly from the AWS Marketplace interface by selecting the EC2 instance type, VPC, subnet, security group, and SSH key pair in a simplified single-page view.
    • Launch through EC2: Redirects you to the full Amazon EC2 Launch Instance wizard with the Marketplace AMI pre-selected. Use this option if you need advanced EC2 configurations such as IAM instance profiles, placement groups, detailed EBS volume encryption, or custom UserData scripts.
  5. Configure the security group rules carefully. Many AWS Marketplace appliances come with a vendor-recommended security group template that opens only the ports required for administrative access (such as SSH on port 22 or HTTPS web management consoles on port 443 or 8443).
  6. Select an existing EC2 key pair (or create a new one) to authenticate to the instance, and click Launch Instance.

Step 5: Deploying via AWS CLI or Infrastructure as Code

Once your AWS account is subscribed to the product in AWS Marketplace, you can launch additional instances programmatically using the AWS CLI, AWS CloudFormation, or Terraform using the regional AMI ID shown on the configuration page.

To launch a subscribed Marketplace AMI using the AWS CLI:

aws ec2 run-instances \
    --image-id ami-0123456789abcdef0 \
    --instance-type m6i.large \
    --key-name my-key-pair \
    --security-group-ids sg-0123456789abcdef0 \
    --subnet-id subnet-0123456789abcdef0 \
    --region us-east-1

If you attempt to run this command before accepting the terms in the AWS Marketplace console, the EC2 API will return an OptInRequired error containing a URL to the AWS Marketplace subscription page.

Step 6: Accessing and Managing Subscriptions

After the instance enters the running state, check the Usage Instructions on the AWS Marketplace configuration page. Vendors often specify a custom default username (for example, admin, ec2-user, or ubuntu) or require you to use the EC2 InstanceId as the initial password for web-based administration portals.

To view, modify, or cancel your active subscriptions:

  1. Open the AWS Marketplace Console and select Manage subscriptions.
  2. Locate the software product in your list of active subscriptions.
  3. To cancel a subscription, first terminate all running Amazon EC2 instances built from that Marketplace AMI across all AWS Regions.
  4. Click Actions next to the subscription and select Cancel subscription.

All AWS Marketplace software charges are consolidated directly into your monthly AWS bill and can be tracked using AWS Cost Explorer by filtering by the Billing Entity: AWS Marketplace dimension.
